# Aneed's eight DJ portraits

These JPGs are sized 720x900 and correspond to `DjProfiles.cs` image paths.

Copy the `AlexiTheMVCBot/wwwroot/img/djs` folder into your local clone of `AlexiTheMVCBot`.

Then run from the repository root:

```powershell
git add AlexiTheMVCBot/wwwroot/img/djs
git commit -m "Add eight DJ portraits"
git push origin feature/eight-dj-personas
```

The portraits are original fictional visual interpretations. Check the appearance of each against the desired shared-template likeness before releasing them publicly.
